Personal portfolio of **Nawaf Alfawzan**, an Information Systems student on the Cybersecurity track at Prince Sultan University in Riyadh. CompTIA Security+ certified and aiming for GRC and cyber risk roles.

**Live site:** https://nniiece.github.io/NawafAlfawzan.github.io/

## What's inside

- **Credentials:** CompTIA Security+, plus programs, course certificates, and a job simulation, each labeled for what it is
- **Experience:** part-time work since 2021, CyberTech Club (Tech Team, PSU CTF 1.0 mentorship), and COOP CLUB (Project Manager)
- **Projects:** malware traffic investigation capstone (graded A), CTF training labs, and a Linux kernel module
- **Learning in public:** cybersecurity blog and club writing
- **Education and skills:** each skill group lists where it was used or learned
- **Journey:** a filterable timeline of milestones and a certification roadmap
- **Beyond the CV:** how I ended up at PSU, and what I do off the clock

## Built with

- A single `index.html` file: plain HTML, CSS, and JavaScript, with no frameworks or build step
- Google Fonts: Big Shoulders Display, Instrument Sans, JetBrains Mono
- Responsive from 320px phones to large desktops, and respects the "reduce motion" setting
- Hosted on GitHub Pages
- Made with Claude

## Run it locally

Download `index.html` and open it in any browser.
